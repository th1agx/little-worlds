# Ferramentas de assets

Esta pasta receberá somente scripts offline e reprodutíveis de validação, inspeção e otimização de assets aprovados.

Nenhum asset, conversão ou script de ingestão é criado no bootstrap. A primeira implementação depende do gate de aquisição e do ledger definidos em `docs/04-production/vertical-slice/ASSET_ACQUISITION_PLAN.md`.
