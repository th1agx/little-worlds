### Exemplos de uso corretos

- “Implemente a rota 2D de Projetos e revise o bundle” → `vercel-react-best-practices`; `playwright` somente se a tarefa incluir teste em browser.
- “Audite o terminal por foco, teclado e fluxo” → skill pública de UX não é usada; aplicar `CHECKLISTS.md` + `UI_UX_ACCESSIBILITY.md` e registrar a lacuna.
- “Revise headers e links externos antes do preview” → `security-best-practices`.
- “Publique um preview Vercel aprovado” → `vercel-deploy`; acrescentar `security-best-practices` para revisão explícita prévia, não para publicar automaticamente.

## Avaliadas e excluídas

| Candidata                                                                                                                  | Decisão                          | Justificativa técnica                                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `web-design-guidelines` (Vercel)                                                                                           | não instalar                     | busca diretrizes de uma URL `main` móvel em cada execução. Conflita com o requisito de comportamento versionado; não há snapshot local no upstream instalado. |
| `playwright-interactive`                                                                                                   | não instalar                     | sobrepõe Playwright; exploração manual já é coberta pelo browser integrado e não deve criar dois fluxos de automação.                                         |
| `threejs-debug-profiler`                                                                                                   | auditar mais; não instalar agora | é o melhor módulo encontrado, mas desconhece lifecycle/cache R3F e budgets locais; serve como insumo, não autoridade.                                         |
| `threejs-qa-release` e `threejs-aaa-graphics-builder`                                                                      | não instalar                     | dependências/hooks/budgets de jogo e direção AAA conflitam com o projeto.                                                                                     |
| `r3f-best-practices`, `three-best-practices`, `web3d-integration-patterns`, `threejs-graphics-optimizer`, `threejs-skills` | não instalar                     | licença ausente/indeterminada em parte dos candidatos e regras genéricas ou contraditórias; detalhes em `VISUAL_BENCHMARK_SKILL_AUDIT.md`.                    |
| skills genéricas de arquitetura/documentação                                                                               | não instalar                     | o repositório já tem ADRs, templates, contexto mínimo e checklists mais específicos; duplicariam instruções.                                                  |
| Sentry / plugins amplos                                                                                                    | adiar                            | só após decisão de observabilidade/privacidade; hoje adicionariam dependência e contexto sem consumidor.                                                      |
