# ADR 0003 — WebGL 2 como baseline

**Status:** accepted — 2026-08-04

## Decisão

Produção começa com WebGL 2. WebGPU poderá ser progressive enhancement após spike, métricas, matriz de browsers e fallback visual equivalente.

## Motivo

A experiência precisa alcançar dispositivos variados. Adotar o renderer mais novo antes de validar R3F, shaders, pós-processamento e Safari adicionaria risco sem benefício comprovado para o MVP.

## Revisão

Reavaliar depois do vertical slice estável e somente via novo ADR.
