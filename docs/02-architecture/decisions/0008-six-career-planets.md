# ADR 0008 — Seis planetas de carreira e um hub

**Status:** proposed — 2026-08-04

## Contexto

A Sprint 0 combinava trajetória profissional com “Sobre” ou omitia uma cena própria. Isso reduz clareza para recrutadores e sobrecarrega a biografia.

## Decisão proposta

O sistema contém Hub mais seis destinos: Sobre Mim, Projetos, Tecnologias, Experiência, Certificados e Contato. Produção continua incremental; a taxonomia não autoriza produzir todos simultaneamente.

## Consequências

- Cada terminal responde a uma pergunta profissional única.
- Experiência ganha narrativa temporal sem poluir Sobre Mim.
- Aumenta uma cena no roadmap; escopo será controlado por reutilização e gates.
