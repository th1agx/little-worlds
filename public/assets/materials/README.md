# Materials

Texturas, atlases, LUTs e recursos compartilhados por materiais.

- Priorizar atlas, vertex color e baixa frequência visual.
- KTX2 quando medição provar benefício; resolução mínima que preserve leitura.
- Não colocar material fotográfico bruto ou 4–8K por conveniência.
- Cada recurso registra color space, canais, dimensões e memória GPU estimada.
