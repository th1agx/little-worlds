# Props

Computadores, bancos, lanternas, telescópios, pontes, escadas e objetos reutilizáveis.

- Subfamília no nome, não em pastas profundas: `props-computer-*`, `props-bench-*`.
- Tela, emissivo ou parte móvel só vira mesh/material separado quando há função.
- Props hero exigem aprovação do Game Director.
- Nenhum prop pode carregar marca, texto de terceiros ou UI rasterizada.
