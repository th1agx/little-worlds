# World

Derivados exclusivos ou estruturais de mundo: terreno, shell arquitetônico, sky resources e colliders de ambiente.

- Runtime: GLB para geometria; KTX2/HDR processado apenas quando aprovado.
- Ownership: cena que declara o asset em manifesto.
- Não colocar aqui vegetação, rocks ou props reutilizáveis.
- Um planeta carregado por vez; assets exclusivos não podem vazar para o chunk global.
