# Music

Faixas musicais aprovadas para runtime.

- Música é opt-in, esparsa e subordinada ao silêncio/ambiente.
- Master fica fora de `public`; somente encode web aprovado é publicado.
- Crédito e restrições de Content ID devem estar resolvidos antes do commit.
- Não usar uma faixa por planeta sem identidade musical global aprovada.
